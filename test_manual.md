### 1 Use PostgreSQL for data storage
* **Status**: ✅ Accepted
* **Decision**: We will use PostgreSQL as our primary database
* **Context**: We need a reliable, ACID-compliant database for our application
* **Consequences**: Requires separate hosting, but provides strong consistency guarantees

### 2 Implement REST API
* **Status**: 📝 Draft
* **Decision**: Build a RESTful API for client communication
* **Context**: REST is well-understood and widely supported
* **Consequences**: Standard approach, good tooling support
